# Road Defect Detection
RoadDefectDetection is a desktop application designed to process aerial drone footage and flight logs to automatically detect potholes. It offers a simple graphical interface (UI) that allows the user to:

- Load a video recorded from a drone
- Load the corresponding drone flight log (.csv)
- Automatically detect potholes in the video
- Save individual pothole images 
- Visualize the drone’s flight path on a map, including detected defect locations



# 🧰 Features
- ✅ User-friendly graphical interface
- 🧠 Automated pothole detection from aerial video
- 📸 Saves each detected pothole as an image
- 🗺️ Map-based visualization of the drone's flight and pothole locations
- 📂 Import video and flight log data easily
